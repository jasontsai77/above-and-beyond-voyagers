# Above & Beyond Voyagers

A premium flight planning service landing page for Singapore-based travelers.

## 🌟 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Elegant navy and gold color scheme with smooth animations
- **Full Sections**:
  - Hero section with call-to-action
  - About us with core values
  - Pricing for 4 travel regions
  - How it works (4-step process)
  - Testimonials from real clients
  - FAQ accordion
  - Contact form with WhatsApp integration
- **Mobile Optimized**: Hamburger menu for mobile navigation
- **Smooth Interactions**: Scroll animations and hover effects
